cmd-engine

AI 终端命令翻译器 —— 用自然语言描述你想做什么，自动生成 Shell 命令。

工作原理

在终端提示符下直接输入你想要的操作（英文），按下 Ctrl+T （可在配置文件中自定义快捷键，见下文）， 守护进程会将你的文本和上下文发送给 LLM，将输入替换为生成的 Shell 命令， 你检查无误后按 Enter 执行。

示例
$ find all files named config in the current folder
▸ Ctrl+T ▸ $ find . -name "config*"

安装配置

  1. 运行交互式安装向导
    ./target/debug/cmd-engine setup
    逐步引导配置 Provider、URL、API 密钥、模型、快捷键、超时 —— 然后自动安装 Shell 钩子，并可选配置 systemd 开机自启。
  2. 或手动配置 — 创建 ~/.config/cmd-engine/config.json： 
    {
  "provider_type": "openai",
  "provider_url": "http://localhost:11434/v1",
  "api_key": "",
  "model": "qwen2.5:3b",
  "daemon_port": 11435,
  "hotkey": "Ctrl+T",
  "session_history_lines": 10,
  "include_env_vars": true,
  "timeout_ms": 5000
}
    然后启动 ./target/debug/cmd-engine & 并手动添加下方 Shell 钩子。

Shell 集成

自定义快捷键： 如需修改快捷键，同步更改 ~/.config/cmd-engine/config.json 中的 hotkey 字段和下方 Shell 脚本中的绑定按键。

bash

将以下内容添加到 ~/.bashrc：

# cmd-engine — AI 终端命令翻译器 (Ctrl+T)
__cmd_engine_translate() {
  local input="$READLINE_LINE"
  [ -z "$input" ] && return

  # 如果守护进程未运行，自动启动
  if ! curl -s --connect-timeout 1 http://127.0.0.1:11435/health > /dev/null 2>&1; then
    local daemon_bin="$HOME/trmnl-cmplt-agent/target/debug/cmd-engine"
    if [ -x "$daemon_bin" ]; then
      { nohup "$daemon_bin" > /tmp/cmd-engine.log 2>&1 & } 2>/dev/null
      disown 2>/dev/null
    fi
    sleep 1
  fi

  printf '\n⏳ translating...\n'

  local resp=$(curl -s --max-time 20 -X POST http://127.0.0.1:11435/translate \
    -H "Content-Type: application/json" \
    -d "$(jq -n \
      --arg input "$input" \
      --arg shell "bash" \
      --arg cwd "$PWD" \
      --arg os "$(uname -s)" \
      '{input: $input, shell: $shell, cwd: $cwd, os: $os, history: []}')")

  local cmd=$(echo "$resp" | jq -r '.command // empty')
  local err=$(echo "$resp" | jq -r '.error // empty')

  if [ -n "$cmd" ]; then
    READLINE_LINE="$cmd"
    READLINE_POINT="${#cmd}"
  elif [ -n "$err" ]; then
    printf '[ERR] %s\n' "$err"
  fi
}
bind -x '"\C-t": __cmd_engine_translate'
等待提示： 等待 LLM 返回时会显示 ⏳ translating... 提示，命令返回后保留在屏幕上作为视觉记录。

zsh

将以下内容添加到 ~/.zshrc：

__cmd_engine_translate() {
  local input="$BUFFER"
  if [ -z "$input" ]; then return; fi
  BUFFER="⏳ translating..."
  CURSOR=0
  zle reset-prompt
  local resp=$(curl -s -X POST http://127.0.0.1:11435/translate \
    -H "Content-Type: application/json" \
    -d "$(jq -n \
      --arg input "$input" \
      --arg shell "zsh" \
      --arg cwd "$PWD" \
      --arg os "$(uname -s)" \
      '{input: $input, shell: $shell, cwd: $cwd, os: $os, history: []}')")
  local cmd=$(echo "$resp" | jq -r '.command // empty')
  local err=$(echo "$resp" | jq -r '.error // empty')
  if [ -n "$cmd" ]; then
    BUFFER="$cmd"
    CURSOR=${#cmd}
  elif [ -n "$err" ]; then
    BUFFER="[ERR] $err"
    CURSOR=0
  fi
  zle reset-prompt
}
zle -N __cmd_engine_translate
bindkey '^T' __cmd_engine_translate

PowerShell

将以下内容添加到 $PROFILE：

Set-PSReadLineKeyHandler -Key Ctrl+T -ScriptBlock {
  $input = $null
  [Microsoft.PowerShell.PSConsoleReadLine]::GetBufferState([ref]$input, [ref]$null)
  if (-not $input) { return }
  [Microsoft.PowerShell.PSConsoleReadLine]::Replace(
    0, $input.Length, "⏳ translating...")
  $body = @{
    input   = $input
    shell   = "pwsh"
    cwd     = (Get-Location).Path
    os      = if ($IsWindows) { "windows" } else { "linux" }
    history = @()
  } | ConvertTo-Json
  $resp = Invoke-RestMethod -Uri "http://127.0.0.1:11435/translate" `
    -Method Post -Body $body -ContentType "application/json" -TimeoutSec 5
  if ($resp.command) {
    [Microsoft.PowerShell.PSConsoleReadLine]::Replace(
      0, $input.Length, $resp.command)
  } elseif ($resp.error) {
    [Microsoft.PowerShell.PSConsoleReadLine]::Replace(
      0, "⏳ translating...".Length, "[ERR] $($resp.error)")
  }
}

配置项说明

字段类型说明
provider_type"openai" | "anthropic"使用的 API 格式
provider_urlstringLLM API 的基础地址
api_keystringAPI 密钥；本地部署无需认证时填 ""
modelstring模型 ID（如 gpt-4o、claude-sonnet-4-20250514、qwen2.5:3b）
daemon_portu16守护进程监听端口（默认 11435）
hotkeystring触发翻译的快捷键（默认 Ctrl+T）。Shell 绑定需与此一致
session_history_linesu8最近几条历史命令作为上下文（默认 10）
include_env_varsbool是否包含关键环境变量如 VIRTUAL_ENV（默认 true）
timeout_msu32LLM 请求超时时间，毫秒（默认 5000）

交互式安装向导

运行安装向导，逐步配置：

./target/debug/cmd-engine setup
# 或: cargo run -- setup

向导包含以下步骤：

  1. 选择 Provider — OpenAI 兼容 或 Anthropic
  2. 设置 Provider URL — 云端预设、本地 Ollama 或自定义
  3. 输入 API 密钥 — 加密输入，本地部署可跳过
  4. 模型 ID — 任意提供商支持的模型
  5. 快捷键 — Ctrl+T（默认）或自定义
  6. 超时 & 历史行数 — 数值，默认 15000ms / 10 行

确认配置后，可选择测试连接、保存配置、 自动安装 Shell 钩子（自动检测 bash/zsh/fish/pwsh）， 并可选择配置 systemd 开机自启动。

API 参考

POST /translate

curl -X POST http://127.0.0.1:11435/translate \
  -H "Content-Type: application/json" \
  -d '{
    "input": "find all files named config",
    "shell": "bash",
    "cwd": "/home/user/projects",
    "os": "linux",
    "history": ["cd projects", "ls -la"]
  }'

成功响应：

{"command": "find . -name \"config*\"", "error": null}

失败响应：

{"command": null, "error": "LLM timeout"}

GET /health

curl -s http://127.0.0.1:11435/health
{"status": "ok"}
