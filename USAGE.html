cmd-engine

AI-powered terminal command translator — type in plain English, get shell commands back.

How it works

You type what you want to do in natural language right at your terminal prompt. Press Ctrl+T (customizable in config — see below). The daemon sends your text + context to an LLM, replaces your input with the generated shell command, and you review it before pressing Enter.

Example
$ find all files named config in the current folder
▸ Ctrl+T ▸ $ find . -name "config*"

Shell integration

bash

Add to ~/.bashrc:

# cmd-engine — AI terminal command translator (Ctrl+T)
__cmd_engine_translate() {
  local input="$READLINE_LINE"
  [ -z "$input" ] && return

  # Auto-start daemon if not running
  if ! curl -s --connect-timeout 1 http://127.0.0.1:11435/health > /dev/null 2>&1; then
    local daemon_bin="$HOME/trmnl-cmplt-agent/target/debug/cmd-engine"
    if [ -x "$daemon_bin" ]; then
      { nohup "$daemon_bin" > /tmp/cmd-engine.log 2>&1 & } 2>/dev/null
      disown 2>/dev/null
    fi
    sleep 1
  fi

  printf '\n⏳ translating...\n'

  local resp=$(curl -s --max-time 20 -X POST http://127.0.0.1:11435/translate \
    -H "Content-Type: application/json" \
    -d "$(jq -n \
      --arg input "$input" \
      --arg shell "bash" \
      --arg cwd "$PWD" \
      --arg os "$(uname -s)" \
      '{input: $input, shell: $shell, cwd: $cwd, os: $os, history: []}')")

  # Stop spinner, clear line
  kill $spinner_pid 2>/dev/null
  wait $spinner_pid 2>/dev/null
  printf '\r\033[K'

  local cmd=$(echo "$resp" | jq -r '.command // empty')
  local err=$(echo "$resp" | jq -r '.error // empty')

  if [ -n "$cmd" ]; then
    READLINE_LINE="$cmd"
    READLINE_POINT="${#cmd}"
  elif [ -n "$err" ]; then
    printf '[ERR] %s\n' "$err"
  fi
}
bind -x '"\C-t": __cmd_engine_translate'
Indicator: A ⏳ translating... message prints while waiting. It stays on screen as a visual log after the command appears.

zsh

Add to ~/.zshrc:

__cmd_engine_translate() {
  local input="$BUFFER"
  if [ -z "$input" ]; then return; fi
  BUFFER="⏳ translating..."
  CURSOR=0
  zle reset-prompt
  local resp=$(curl -s -X POST http://127.0.0.1:11435/translate \
    -H "Content-Type: application/json" \
    -d "$(jq -n \
      --arg input "$input" \
      --arg shell "zsh" \
      --arg cwd "$PWD" \
      --arg os "$(uname -s)" \
      '{input: $input, shell: $shell, cwd: $cwd, os: $os, history: []}')")
  local cmd=$(echo "$resp" | jq -r '.command // empty')
  local err=$(echo "$resp" | jq -r '.error // empty')
  if [ -n "$cmd" ]; then
    BUFFER="$cmd"
    CURSOR=${#cmd}
  elif [ -n "$err" ]; then
    BUFFER="[ERR] $err"
    CURSOR=0
  fi
  zle reset-prompt
}
zle -N __cmd_engine_translate
bindkey '^T' __cmd_engine_translate

PowerShell

Add to $PROFILE:

Set-PSReadLineKeyHandler -Key Ctrl+T -ScriptBlock {
  $input = $null
  [Microsoft.PowerShell.PSConsoleReadLine]::GetBufferState([ref]$input, [ref]$null)
  if (-not $input) { return }
  [Microsoft.PowerShell.PSConsoleReadLine]::Replace(
    0, $input.Length, "⏳ translating...")
  $body = @{
    input   = $input
    shell   = "pwsh"
    cwd     = (Get-Location).Path
    os      = if ($IsWindows) { "windows" } else { "linux" }
    history = @()
  } | ConvertTo-Json
  $resp = Invoke-RestMethod -Uri "http://127.0.0.1:11435/translate" `
    -Method Post -Body $body -ContentType "application/json" -TimeoutSec 5
  if ($resp.command) {
    [Microsoft.PowerShell.PSConsoleReadLine]::Replace(
      0, $input.Length, $resp.command)
  } elseif ($resp.error) {
    [Microsoft.PowerShell.PSConsoleReadLine]::Replace(
      0, "⏳ translating...".Length, "[ERR] $($resp.error)")
  }
}

Configuration reference

FieldTypeDescription
provider_type"openai" | "anthropic"Which API format to use
provider_urlstringBase URL of the LLM API
api_keystringAPI key; "" for local providers with no auth
modelstringModel ID (gpt-4o, claude-sonnet-4-20250514, qwen2.5:3b)
daemon_portu16Port the daemon binds to (default 11435)
hotkeystringKey combo for translation trigger (default Ctrl+T). The daemon uses this to validate config; shell bindings must match
session_history_linesu8How many recent commands to send as context (default 10)
include_env_varsboolInclude key env vars like VIRTUAL_ENV (default true)
timeout_msu32Max wait time for LLM response (default 5000)

Interactive setup

Run the setup wizard — it guides you through every step:

./target/debug/cmd-engine setup
# or: cargo run -- setup

The wizard will:

  1. Choose provider — OpenAI-compatible or Anthropic
  2. Set provider URL — Cloud preset, local Ollama, or custom URL
  3. Enter API key — masked input, skip for local providers
  4. Model ID — any model your provider supports
  5. Hotkey — Ctrl+T (default) or custom
  6. Timeout & history — numeric, defaults 15000ms / 10 lines

After the summary, it optionally tests the connection, saves the config, auto-installs the shell hook (detects bash/zsh/fish/pwsh), and optionally sets up systemd auto-start at boot.

API reference

POST /translate

curl -X POST http://127.0.0.1:11435/translate \
  -H "Content-Type: application/json" \
  -d '{
    "input": "find all files named config",
    "shell": "bash",
    "cwd": "/home/user/projects",
    "os": "linux",
    "history": ["cd projects", "ls -la"]
  }'

Response (success):

{"command": "find . -name \"config*\"", "error": null}

Response (failure):

{"command": null, "error": "LLM timeout"}

GET /health

curl -s http://127.0.0.1:11435/health
{"status": "ok"}
